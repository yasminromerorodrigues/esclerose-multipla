# Tudo sobre esclerose múltipla

Guia em português sobre esclerose múltipla: sintomas, primeiros passos após o diagnóstico, ferramentas, direitos, pesquisas e histórias reais. Criado por Yasmin.

## Como publicar no GitHub Pages

1. Crie uma conta gratuita em github.com.
2. Clique em **New repository**. Dê o nome `esclerose-multipla`, deixe como **Public** e clique em **Create repository**.
3. Na página do repositório, clique em **uploading an existing file** (ou **Add file > Upload files**).
4. Arraste **todos os arquivos desta pasta** (não o .zip) e clique em **Commit changes**.
   O arquivo `.nojekyll` pode ficar oculto no seu computador; se não aparecer, tudo bem.
5. Vá em **Settings > Pages**. Em **Source**, escolha **Deploy from a branch**, selecione a branch **main** e a pasta **/(root)**, e clique em **Save**.
6. Espere de 1 a 3 minutos. O site fica em `https://SEU-USUARIO.github.io/esclerose-multipla/`.

## Depois de publicar

- Envie o endereço final para o Claude: ele ajusta a imagem de prévia do WhatsApp e das redes, que precisa do link completo.
- Para usar um domínio próprio (.com.br), vá em **Settings > Pages > Custom domain** e configure o DNS no Registro.br.

## Como atualizar

Para trocar o site, envie a nova versão do `index.html` em **Add file > Upload files** com o mesmo nome. Ele substitui o anterior.
